# FinTrack

Aplicación web de finanzas personales construida progresivamente.

## Stack inicial
- React
- TypeScript
- Vite
- CSS

## Reglas
- Mantener el código simple, claro y fácil de aprender.
- No instalar dependencias sin necesidad.
- No agregar funcionalidades no solicitadas.
- Modificar únicamente los archivos necesarios.
- Evitar sobreingeniería.
- Reutilizar componentes cuando sea razonable.
- Mantener explicaciones finales breves.
- No crear backend ni base de datos hasta que se solicite.
